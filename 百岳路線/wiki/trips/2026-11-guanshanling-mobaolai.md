# 2026-11 關山嶺上溪頭魔保出向陽

- **攀登日期**：2026/11/14（六）– 11/15（日），預備日 11/16（一）
- **隊伍規模**：6 人（新 3；舊 3），政大登山隊
- **對應路線**：[[guanshanling-xitou-mobaolai-xiangyang|關山嶺上溪頭魔保出向陽]]
- **醫療與應變參照**：[[ams-protocol|高山反應處置與預防]]、[[wilderness-medical-protocol|野地醫療應變計畫]]

## 行程架構摘要
- **D0（11/13）**：台北車站（11:35 普悠瑪 420）→ 池上火車站（15:20）→ 池上民宿（D0 須完成隔日行動糧採買）。
- **D1（11/14）**：05:15 池上出發 → 07:00 向陽管制站開放 → 07:30 [[guanshanling|關山嶺山]]登山口 → 09:15 關山嶺山 → 11:15 [[xitou-hut-ruins|溪頭山山屋遺址]] → 13:00 [[xitou-mountain|溪頭山]] → 14:10 [[small-camp-pond|小營地＋池子]] → 16:35 [[mobaolai|魔保來山主峰]] → 17:05 [[mobaolai-north-camp|魔保來山北側營地]]（重裝 4.06k、輕裝 0.38k，+766m / -232m，9.5 hr）。
- **D2（11/15）**：06:00 營地起登 → 06:40 3316 峰 → 10:30 向陽傳統路 7K → 12:00 [[xiangyang-hut|向陽山屋]] → 13:20 向陽登山口（重裝 8.84k，+262m / -1203m，5h 40m）。

## 審核重點與風險筆記
1. **步程保守估計**：安全委員與審核意見指出，2022 年紀錄隊伍為 60+ 百岳老手，不可直接套用於「3 舊 3 新」隊伍；尤其[[xitou-mobaolai-bamboo-and-scree|溪頭山至看天池密箭竹海]]及營地至 7K 路段，應預留 1–2 小時緩衝以避免冬季（17:11 日落）摸黑。
2. **公私水負重**：D1 公水 6L（6 人均分 1L）＋兩日行進私水 3L，每人背負約 4–5L 水量；看天池僅作備援。
3. **通訊與裝備**：營地無訊號，急用可至 `23.28398, 120.973167` 使用中華電信；建議前、中、壓隊攜帶 3 支無線電，並必備安全頭盔、保暖手套、擋風板與 10m 扁帶／大 D。
